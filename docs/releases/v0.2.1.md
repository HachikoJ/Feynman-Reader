# v0.2.1 - 2026-09-09

修复封面上传、替换或移除后刷新恢复旧值的问题，并修复同类云端同步缺陷。

## 修复内容

- 作者、简介、封面和标签支持明确清空。修改书籍资料只写资料字段，保留数据库中的分析和学习记录。
- 图片读取期间等待保存；取消旧读取，支持重复选择同一文件，读取失败可见。
- 书单成员移除、书单删除和书籍关系删除使用账号隔离的单条接口，刷新后不会被旧快照重新添加。
- AI 用量单独追加并支持幂等重试，不再触发全量书籍和设置导入。导入与迁移保留已有头像、昵称等个人资料。
- 刷新等待正在保存的数据，迟到的读取响应不会覆盖新编辑；被拒绝的书籍保存返回冲突提示。
- 回收站中的书籍不能被旧详情页保存而意外恢复。

## 验证与恢复

沿用 v0.2.0 的 L2 公开产品验收基线，复核本次受影响的交互、同步接口与账号隔离。回归覆盖封面替换和清空后的重新读取、上传取消和延迟读取、保存失败、组织删除、用量独立保存，以及实际 PostgreSQL 临时表隔离验证。

此版本不新增数据库迁移，不恢复历史数据，不重置管理员认证器。版本标签不可覆盖；源码包、SHA-256 和清单对应同一提交。应用回退可使用上一发布目录或 v0.2.0 标签，保留当前数据库和私有配置；回退后将重新具有旧版本的同步缺陷。详细操作见[版本发布与恢复](../operations/releases-and-rollback.md)。
