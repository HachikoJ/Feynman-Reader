# v0.4.4

本版本修正费曼小助手的引用范围：回答只围绕用户本轮明确引用的对象，不再把复习提醒、当前书籍或其他会话资料强行带进回答。

## 引用范围

- 用户提到书名或通过 `@` 选择书籍时，只使用与该问题相关的这本书资料。
- 用户使用附件提问，或没有另行指定书籍时，使用当前会话中的附件；此时不会自动扩展为整本书及其学习记录。
- 用户选中原文或选中内容时，只使用这段选中内容，不自动把整本书、复习历史或未引用附件加入本轮回答。
- 只有用户同时引用书籍、选中内容和附件时，小助手才会综合这些对象。

## 主动复习

- 费曼学习提醒和已有复习记录仍可保留在会话中，但不会成为回答普通问题的前置条件。
- 引用对象资料不足时，小助手直接说明缺少什么，不再要求用户先完成复习，或用未引用资料补足答案。

本版本不涉及数据库结构、账号权限或已保存凭据行为变更。

## English

Version 0.4.4 scopes Feynman Assistant replies to the objects explicitly referenced in the current turn. Mentioning or selecting a book uses only relevant material for that book. Asking with an attachment, or asking without pointing to a book, uses current-session attachments without expanding into a whole book or its learning history. Selected text is treated as its own reference. The assistant combines multiple kinds of objects only when the user references them together.

Review reminders and earlier learning records may remain in a conversation, but they do not become prerequisites for answering a direct question. When the referenced material is insufficient, the assistant states the gap instead of asking the user to review first or padding the answer with unreferenced content.

No database schema, account permission, or stored credential behavior changes.
