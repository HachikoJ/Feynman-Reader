# v0.2.2

产品文案统一围绕个人阅读与练习，覆盖引导、登录、账号中心、设置、文档上传、费曼小助手及保存失败提示，与中英文 README 和 GitHub About 保持一致。

隐私说明保留并澄清实际服务端存储、AI 数据传输、密钥、Cookie、导出和删除边界。本次不改变数据处理方式、同意控制、账号权限或学习记录保存逻辑，也不迁移或恢复历史数据。

## 验证与恢复

- 71 组、541 项现有测试通过，TypeScript 检查和生产构建通过。
- ESLint 无错误，保留 107 条既有警告；生产依赖审计无漏洞。
- 使用虚构普通账号检查桌面与手机端的引导、账号中心、设置和隐私页面；GitHub 账号中心截图同步更新。修正英文手机设置页中长链接导致的横向溢出，17 项设置测试复核通过。
- 无新数据库迁移。保留 v0.2.1 标签与旧部署目录；回退应用时保留当前数据及服务器配置，参见[版本发布与恢复](../operations/releases-and-rollback.md)。

## English

Product copy now focuses on personal reading and practice across onboarding, sign-in, Account Center, settings, document upload, the assistant, and save errors, matching both READMEs and GitHub About. The privacy notice clarifies existing server storage, AI transfers, credentials, cookies, exports, and deletion without changing data handling, consent controls, permissions, or persistence behavior.
