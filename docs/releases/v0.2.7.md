# v0.2.7

费曼小助手的回答现在会把匹配到的书籍、读书笔记、阶段学习、费曼实践和角色问答记录展示为“参考来源”标签。标签只包含经过清理和数量限制的定位信息；点击后会打开对应书籍，切换到相关页面，自动展开目标记录，并滚动到具体内容后短暂高亮。电脑上可用新窗口打开标签，移动端标签会换行完整显示。

用户取消观猹登录时，OAuth 回调不再直接展示原始 JSON。服务端会清理待处理的 PKCE Cookie，并回到可读的登录页面，说明授权未完成且账号信息未改变，同时保留原本要返回的页面。

用户取消 TokenDance AI Key 授权时，设置页会显示明确的中性提示，清理浏览器中的待处理授权状态和回调参数，不会修改已保存的 API Key。其他授权失败也会显示可读的未完成提示，不暴露上游响应代码。

本版本不涉及数据库结构、账号权限或已保存凭据行为变更。旧会话仍可正常读取，没有来源信息的历史回答不会补造标签。保留 v0.2.6 及部署前私有备份，参见[版本发布与恢复](../operations/releases-and-rollback.md)。

## English

The Feynman assistant now displays matched books, reading notes, learning phases, Feynman practice records, and role Q&A records as reference tags. Each tag carries only cleaned, bounded target metadata. Selecting it opens the relevant book or learning tab, expands the target record, and scrolls to the exact item with a short highlight. Tags can be opened in a new window on desktop, and they wrap without truncating on mobile.

Cancelling Watcha sign-in no longer leaves the browser on a raw JSON OAuth response. The server clears the pending PKCE cookie and redirects to a readable login page that explains that authorization was not completed and the account was unchanged, while preserving the requested return destination.

Cancelling TokenDance AI key authorization now shows a clear, neutral status in Settings. The browser's pending authorization state and callback parameters are cleared without changing the saved API key. Other authorization failures also receive a readable incomplete-authorization message without exposing upstream response codes.

This release changes no database schema, account permissions, or stored credential behavior. Existing sessions remain readable; historical replies without source metadata are not given fabricated tags. Retain v0.2.6 and private deployment backups for rollback. See the [version and recovery guide](../operations/releases-and-rollback.md).
