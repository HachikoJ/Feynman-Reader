# v0.2.0 - 2026-09-09

本版本汇集备案恢复后的账号与 AI 接入、学习数据可靠性、完整系统管理和暗色模式改进，是首个正式 Git 标签版本。

## 主要更新

- 恢复观猹登录与 TokenDance 接入，补齐 ICP 页脚及 `https://www.deline.top` 请求归因。
- 修复费曼评估无反馈、学习数据读取失败及重新打开书籍后已生成分析未显示的问题。
- 系统管理保留看板，新增 19 张数据表详情、用户头像与用户名、受控编辑和删除、账号启停、加密操作存档与恢复。
- 管理员入口、页面、接口及管理脚本由服务端保护；修复表单来源校验，保留唯一身份与 TOTP 双重验证。
- 改善暗色复习卡片的文字和按钮对比度，四处 TokenDance 标志随应用主题切换。

## 版本与恢复

标签 `v0.2.0` 固定本次提交。Release 附件包含源码包、SHA-256 校验文件和提交清单；后续修复发布新标签，不覆盖此版本。部署目录记录版本及完整提交号。

恢复步骤与兼容性边界见 [版本发布与恢复](../operations/releases-and-rollback.md)。恢复应用代码不会自动恢复 PostgreSQL、环境文件、API Key 或认证器配置；不要覆盖上线后的学习数据。

## 升级要求

唯一管理员身份从源码移至服务端配置。升级前将现有管理员的账号 UUID 与观猹主体分别写入 `FEYNMAN_ADMIN_USER_ID`、`FEYNMAN_ADMIN_PROVIDER_SUBJECT`，保持原账号绑定和 TOTP。存在管理员但配置不完整或不匹配时，部署检查会拒绝发布。

迁移 `013_admin_data_changes.sql` 新增加密操作存档。应用回退应保留新表、审计和后续数据，不执行数据库降级。管理员页面及 Nginx 同源策略必须配套更新。

## 验证范围

TypeScript、全量单元测试、ESLint、生产构建、生产依赖审计及 Git 差异检查；手机和桌面的亮暗主题、四处品牌标志与线上健康状态。真实用户的 OAuth 往返与 TOTP 登录需要用户本人完成，发布验证不会代替用户认证或修改其学习记录。

## English

The first tagged release restores post-ICP Watcha and TokenDance integration, fixes evaluation feedback and persisted analysis loading, adds detailed and audited administration, and improves dark-mode review cards and TokenDance branding.

Use the immutable version tag, source archive, SHA-256 checksums, and full commit manifest to identify this release. Application rollback does not restore databases, environment files, encryption keys, or TOTP enrollment.

Before upgrading, configure the existing administrator binding in server-only `FEYNMAN_ADMIN_USER_ID` and `FEYNMAN_ADMIN_PROVIDER_SUBJECT`. Keep the same account and authenticator. Migration 013 adds encrypted change history; retain that table and later user data when rolling back application code. See the linked recovery guide for details.
