# v0.4.0

本版本完善了外部笔记导入与书架的关联：导入前会识别书名和作者，优先关联已有书籍，找不到时自动创建书籍并把笔记一次性写入。

## 导入关联

- Readwise 使用书名与作者匹配书架；书名会忽略常见书名号、空白和电子书文件扩展名。
- 微信读书、Kindle、Apple Books 和带书名列的 CSV 会尽量提取书籍信息；无法从导出文本判断书名时，界面要求补充书名。
- Zotero 会读取批注所属父文档及书目信息，并按父文档分组。一个账号里的多本书不会被导入到同一本书。
- 从阅读页打开导入窗口时，阅读页当前书籍优先于自动匹配结果；导入底部仍可手动改选其他书籍。
- 云端书架的摘要记录会在追加笔记前自动读取完整详情，避免覆盖已有学习数据。

## 兼容与恢复

本版本不涉及数据库结构、账号权限或已保存凭据行为变更。上线前已在 GitHub 保留线上 v0.3.0 的不可变快照 `deploy-v0.3.0-b8e418d`，新版本通过独立的 `v0.4.0` 标签发布。应用回滚与数据库恢复仍是两项独立操作，参见[版本发布与恢复](../operations/releases-and-rollback.md)。

## English

Version 0.4.0 associates imported highlights and notes with bookshelf books. The importer matches normalized title and author metadata, creates a new book when no match exists, keeps Kindle, Zotero, and multi-book CSV imports book-scoped, and asks for a title when an export does not provide one. A reading-page target takes priority and can still be overridden before import. Cloud summary books are reloaded before appending notes. No database schema, account permission, or stored credential behavior changes.
