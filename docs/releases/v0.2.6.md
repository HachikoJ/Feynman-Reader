# v0.2.6

书架、阅读页和设置页的切换现在会保留浏览器历史。浏览器回退会回到上一个工作区视图，不再直接退出单页阅读工作台；前进可以恢复对应视图和书籍。

阅读页的阶段学习、费曼实践、笔记和相关推荐等子步骤也会写入历史，回退时恢复上一个子步骤。异步读取书籍时会忽略已经被后续回退或导航取代的旧请求。

本版本不涉及数据库结构、登录认证或账号权限变更。保留 v0.2.5 及部署前私有备份，参见[版本发布与恢复](../operations/releases-and-rollback.md)。

## English

Navigation between the bookshelf, reading workspace, and settings now preserves browser history. Back returns to the previous workspace view instead of leaving the single-page reader, and forward restores the corresponding view and book.

Reading tabs such as learning phases, Feynman practice, notes, and recommendations are also recorded as history steps. Back restores the previous sub-step, while asynchronous book loads ignore requests superseded by a later back or navigation action.

This release changes no database schema, authentication flow, or account permissions. Retain v0.2.5 and private deployment backups for rollback. See the [version and recovery guide](../operations/releases-and-rollback.md).
