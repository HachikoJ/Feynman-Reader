# v0.4.1

本版本集中修复导入文档后的解析噪声、章节目录和阅读排版问题。

## 解析与封面

- 清理 BOM、零宽字符、控制字符、软连字符、私有区字符和替换字符，并在章节索引前统一处理，保证划线、书签和 AI 引用偏移一致。
- EPUB 读取 EPUB 3 `nav.xhtml` 与 EPUB 2 `toc.ncx`；保留脚注标记并把脚注内容转换为独立引用块。
- FB2 支持 `<coverpage>` 与 `<binary>` 封面，包括自闭合 `<image />` 写法。
- PDF 读取标题和 outline，改善双栏文本顺序，识别跨栏段落边界，并在浏览器可用时用第一页作为封面回退。

## 阅读呈现

- 正文使用稳定阅读列宽、衬线字体和自然段节奏。
- 标题、引用、表格、代码块和章节续页保持更清晰的间距与分页边界。

## 兼容边界

扫描型或无文字层 PDF、DRM EPUB/AZW 仍会明确提示转换或 OCR，不会强行导入不可读内容。

本版本不涉及数据库结构、账号权限或已保存凭据行为变更。应用回滚与数据库恢复仍是独立操作，详见[版本发布与恢复](../operations/releases-and-rollback.md)。

## English

Version 0.4.1 improves imported document cleanup, EPUB navigation and footnotes, FB2 and PDF cover recovery, PDF two-column ordering, and the reader's typography and block layout. Scan-only or DRM-protected files remain explicit unsupported cases. No database schema, account permission, or stored credential behavior changes.
