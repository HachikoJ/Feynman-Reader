# v0.4.3

本版本修复阅读目录层级、Markdown 渲染和划线文本导入。

## 阅读目录

- 目录按「卷 / 部 → 章 → 节 → 子标题」呈现层级。EPUB 3 导航、EPUB 2 NCX 和 MOBI 目录的嵌套深度会保留，正文里额外的 Markdown 标题会补进所属章节。
- 长章节的性能续页不再作为「（续）」条目出现在目录里；一个真实章节在目录里只有一项。
- 旧书没有保存层级时，阅读器按标题文本里的「第 X 卷 / 章 / 节」、`1.2.3` 编号等线索推断层级；只出现一种线索时保持平级，避免把「序」和「第一章」这类同级标题错误嵌套。
- 点击目录会切到对应分节并滚动到标题本身，滚动过程中高亮当前标题，不再只按字符比例估算位置。

## Markdown 渲染

- `#` 到 `######` 渲染为层级递减的标题，修复 `###`、`####`、`#####` 原样显示在正文中的问题。支持结尾井号、最多三个空格缩进、无空格的 `###标题` 与 Setext（`===` / `---`）标题。
- 围栏代码里的伪标题、`#include`、`#!/bin/sh`、`#fff` 等文本不会被当成标题或目录项。
- 有序列表在松散列表和分节边界上保持连续编号，并支持显式起始序号，不再整段都显示 1；同层混排的有序与无序项按类型分别渲染。
- 引用支持嵌套层级，任务清单、分割线、表格分隔行与图片语法一并修正。内嵌和站内图片直接渲染，远程图片降级为链接，不自动加载外部资源。

## 划线导入

- CSV / TSV 粘贴导入识别 Readwise、Kindle 等常见表头的多种写法（大小写、空格、中文别名）与 BOM，支持逗号、分号、制表符分隔和 `sep=` 声明。
- 支持带引号的多行字段，并解析位置与标注时间列，不再依赖固定列序。
- 导入完成后关闭导入对话框并返回书架。

本版本不涉及数据库结构、账号权限或已保存凭据行为变更。

## English

Version 0.4.3 fixes the reading table of contents, Markdown rendering, and pasted highlight imports.

The table of contents is now a 卷 / 章 / 节 / 子标题 tree. EPUB 3 navigation, EPUB 2 NCX, and MOBI depth are preserved, extra Markdown headings inside a chapter become sub-entries, and pagination continuations no longer appear as `（续）` entries. Books without a stored level infer it from 「第 X 卷 / 章 / 节」and `1.2.3`-style numbering, and only when the titles carry more than one structural cue so that sibling titles stay flat. Clicking an entry switches to the owning section and scrolls to the heading itself, and the current heading stays highlighted while scrolling.

Markdown H1-H6 now render as distinct heading levels instead of literal `###` text, including closing hashes, spaced and spaceless ATX forms, and Setext underlines, while fenced code, shebangs, colour values and `#include` stay plain text. Ordered lists keep continuous numbering across loose lists and honours explicit starts, mixed ordered / unordered siblings render as separate lists, and nested blockquotes, task lists, thematic breaks, tables and images were corrected in the same pass. Inline and in-app images render; remote images degrade to links instead of loading external resources.

CSV and TSV pasted exports accept localized and case-insensitive header aliases, BOM, `sep=` declarations, comma / semicolon / tab delimiters, quoted multi-line fields, and location or highlight-time columns. After an import succeeds the dialog closes and returns to the bookshelf.

No database schema, account permission, or stored credential behavior changes.
