## 数据来源 / Data Sources

- 使用虚构普通账号“林间读者”。书架、学习记录、活动、评分、会话和记忆由模拟 API 提供，不涉及生产账号或数据库。
- 《追风筝的人》的封面与部分阶段内容复用项目公开示例；其他封面为演示用文字封面，不是对应图书的官方封面。
- 讲解、问答、点评和助手对话为展示编写。没有为拍摄调用收费 AI，模拟评分不构成模型能力或学习效果的证明。
- 截图保留真实界面布局与控件，仅隐藏本地开发工具指示器；教学、问答和桌面助手采用实际组件裁切。

The account and personal records are fictional API fixtures. The Kite Runner cover and some phase content reuse the public sample; other covers are demonstration artwork, not official editions. Dialogue, answers, and scores are illustrative, with no paid AI requests or production database access. Screenshots retain the actual layout and controls, with only the local developer indicator hidden; some capture an individual component.
