# 第 7 天作业 - 增长、定价、Token 成本和 PMF

产品已经可以直接访问：[https://www.deline.top](https://www.deline.top)

现在的产品不是帮人快速总结一本书。用户得自己把书讲一遍，AI 再用 3 个角色问问题。这个动作有门槛，但也是它和普通 AI 阅读工具不一样的地方。

## 我会怎么找第一批用户

我先不投流，先去技术学习群、考证群和读书会里找 30 个人。做一个「7 天讲清一本书」的小挑战，每个人拿一本自己正在读的书，完成一次教学模拟和 3 个角色问答。

我先看两个数据：有多少人愿意写完 200 字的教学模拟；被判不通过后，有多少人会回来重答。前者能看出这件事有没有人愿意做，后者能看出 AI 的反馈有没有用。

后面可以做学习成果卡，只放书名、得分、3 题是否通过和一条建议，不公开原回答。用户能发，别人也能看懂这是一个练习理解的产品。

我会把「教学模拟和 3 题都通过」的人数当成主要指标。打开过页面不算，讲完并改过才算。

## 收费先怎么做

现在用户可优先通过 TokenDance / TokenPay 配置 API Key，书和学习记录也留在浏览器里。这个阶段我会先做本地版，不急着收月费。

| 版本 | 价格 | 内容 |
| --- | ---: | --- |
| 体验版 | 免费 | 先走完一次教学模拟和角色问答。 |
| 本地版 | 29 元一次性 | 用户自带 API Key，能保存书、记录和导出数据。 |
| Pro 版 | 39 元/月，后面再做 | 平台提供 AI 额度、云同步和复习提醒。 |

先卖本地版，模型费用由用户自己承担。等有人会回来复习，也愿意为省事付钱，再做 Pro。

## Token 成本怎么控

当前版本不提供平台代付 Token，模型费用由用户自己的 API Key 承担。根据当前使用情况粗略估算，一本书完整使用六阶段分析、教学评估、角色问答、重新生成、相关推荐、标签生成等 AI 功能，费用大约为 0.02 元。

- 文档按段处理，只带当前问题相关的片段。
- 六阶段结果生成过一次就缓存，资料没变不重新生成。
- 角色题重答时，只重评这一题。
- 每种任务限制输出长度，别生成一大段用户不会看的内容。

Pro 版也不做无限调用，按「完整练习包」给额度。一个练习包包含六阶段、一次教学评分、出题和一次问答评分。

`deepseek-v4-flash` 的价格可能调整，0.02 元只是参考估算，不是固定价格。TokenDance 的折扣、分润和活动期限以其官方计费标准及通知为准，不承诺永久或长期有效。实际费用会随调用次数、输入长度和附件解析字符数量波动。

## 我怎么判断它有没有用

先找这 30 个人跑 4 周。

- 第 1 周，看多少人完成第一次教学模拟。
- 第 2 周，找没完成的人聊聊，看看是输入太难、反馈不够具体，还是流程太长。
- 第 3 周，让已经学过的人回来重讲一次，看表达有没有变清楚。
- 第 4 周，测试 29 元本地版，也问他们「这个产品没了，你会不会觉得可惜」。

我先给自己定几条线：35% 的人当天完成教学模拟；20% 的人 7 天内完成 3 个角色问答；没通过的人里至少一半会重答；7 天后有 25% 的人回来继续学；访谈里有 40% 的人说没有它会觉得可惜。

这些数不够，我会先改第一步和 AI 反馈，不急着继续堆功能。
