# 费曼阅读器目录与排版验收

这是一段验收用正文，用来检查真实浏览器中的目录层级、标题锚点和 Markdown 排版。

## 第一卷 基础篇

### 第一章 从问题开始

章节开头正文。这个标题应当作为第一卷下的章级目录出现。

#### 1.1 问题比答案重要

子标题正文，包含一段足够长的说明文字，用于观察标题滚动定位和当前目录高亮。

##### 更深一层的问题

这里应当显示为普通文本标题，而不是泄漏五个井号。

###### 最深层的小节

这里应当显示为普通文本标题，而不是泄漏六个井号。

####### 七个井号不是 Markdown 标题

这一行应当保留原始井号，防止把超出 H6 的写法误判为标题。
